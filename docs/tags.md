# レポートタグ規則（tags）

`corpus/*.md` と `reviews/*/final.md` の frontmatter に付与する `tags` の統制語彙と付与ルールです。
タグの用途は次の2つ。

1. レビュー（`review_report`）が条件の近い過去レポートを本文を読まずに検索するため
2. 文体プロファイル蒸留（`distill_style_profile`）が「どの条件下でどの文章の癖が出るか」を分析するため

## 付与ルール

- **対象**: `corpus/*.md` と `reviews/*/final.md`。draft.md には付与しない（レビュー時は draft 本文から条件を読み取る）
- **付与者**: `import_report` / `register_final` が登録時に本文から自動考案して付与する
- **形式**: frontmatter にフラットな1行の YAML リストで記載する

  ```yaml
  tags: [晴れ, 標高2000m台, 眺望良好, 難度高, 岩場・鎖場, 小屋泊, 縦走, リベンジ・宿題]
  ```

- 並び順は下記の軸の掲載順を目安とする（厳密でなくてよい）
- **値は下記の統制語彙からのみ選ぶ。語彙にない新しい値が必要だと感じた場合は、勝手に使わず、既存値で代用できないか確認したうえでユーザーに承認を求め、承認後に本ファイルへ追記してから使う**
- 本文から明確に読み取れない軸は省略する（推測で埋めない）。ただし標高帯は山の一般知識で補ってよい（おおよそで可）
- 日付・季節は `published_at`（山行日）から導出できるためタグにしない

## 統制語彙

### 天候（0〜複数）

`晴れ` / `曇り` / `雨` / `雪` / `ガス` / `強風` / `猛暑`

- 山行中に変化した場合は複数付与してよい（例: 晴れのち雨 → `晴れ, 雨`）
- `雪` は降雪だけでなく積雪・雪上歩行も含む
- 本文に天候の記述がない場合は省略する

### 標高帯（原則1つ）

`標高1000m未満` / `標高1000m台` / `標高2000m台` / `標高3000m級`

- 山行の最高到達点のおおよそのバンド。正確な数値は不要
- 山に登らないハイキング・古道歩きの回は省略してよい

### 眺望（1つ）

- `眺望良好`: 山行のハイライトとなる眺望が得られた
- `眺望一部`: 断続的・部分的にのみ得られた（一瞬の晴れ間、道中のみ、山頂のみ等）
- `眺望なし`: ガス・雲・樹林などでほぼ得られなかった
- 眺望への言及がない回は省略する

### 難度・苦労（1つ）

- `難度低`: 危険や強い苦労の記述がほとんどない
- `難度中`: 一部の区間に難所・苦戦がある
- `難度高`: 全体として過酷で、強い消耗・緊張が山行の主題になっている

### 道の特徴（0〜複数）

`岩場・鎖場` / `藪漕ぎ` / `渡渉` / `崩落・荒廃` / `ルート不明瞭`

- 本文で難所・特徴として語られている場合のみ付与する（軽く触れられる程度なら省略）

### 行程タイプ（1つ。修飾は複数可）

- `日帰り`: 単発の日帰り山行（前泊のみで登るのは1日の回を含む）
- `小屋泊`: 山中泊（小屋泊）を含む行程
- `連日遠征`: 複数日の山旅の一日（前後の日にも山行がある回）
- 修飾（該当時に追加）: `縦走` / `離島` / `古道・ハイキング`

### 時間制約（該当時のみ）

- `時間制約`: 最終バス・船便・日没・営業時間などのリミットとの勝負が本文で語られる回

### 再訪・因縁（該当時のみ）

- `再訪`: 同じ山・エリアへの再訪
- `リベンジ・宿題`: 過去の撤退・断念への再挑戦、または「宿題」「因縁」「難題」など積年の課題の回収として明示的に位置づけられた回

### バッジ・企画（該当時のみ）

- `バッジ企画`: YAMAP のデジタルバッジ・キャンペーン参加が山行の主目的として明示されている回

### アクシデント（該当時のみ）

`道迷い` / `装備トラブル` / `計画変更` / `撤退・断念`

- `計画変更`: 通行止め・交通トラブル・天候などによる当日のルート・計画変更
- `撤退・断念`: 登頂や目標の断念（過去の山行の話ではなく、当該山行での出来事のみ）

### 特筆（該当時のみ）

`花・植物` / `動物との出会い` / `人との交流` / `歴史・信仰`

- 本文で印象的な収穫・話題として扱われている場合のみ付与する

## 利用方法

- `review_report`: draft.md から山行条件を読み取り、`corpus/*.md`・`reviews/*/final.md` の frontmatter を横断検索して類似条件の回を特定する（本文の追加読み込みは CLAUDE.md「参照の原則」の範囲内で）
- `distill_style_profile`: 対象レポートの列挙時にタグも控え、条件依存の文体傾向（例: 眺望なしの回の締め方、時間制約の回の枠づけ）の分析に用いる
